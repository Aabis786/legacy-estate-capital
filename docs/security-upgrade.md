# Next.js security upgrade — November 6, 2026

## Change

- Next.js pinned from `16.4.0` to `16.4.5`.
- pnpm lockfile regenerated by pnpm 10.11.0; matching Next.js runtime/compiler packages resolve to the patched release.
- React and React DOM remain at `19.2.0`; no application behavior or PHP processing changes were required.
- CI now audits dependencies at all published severity levels before building.

The maintainer advisory [GHSA-pc58-hwjq-p385](https://github.com/vercel/next.js/security/advisories/GHSA-pc58-hwjq-p385) identifies 16.4.5 as patched. The [maintainer advisory index](https://github.com/vercel/next.js/security/advisories) is the reference for ongoing maintenance.

## Verification

- Installed Next.js version: 16.4.5.
- Production static export: passed with no security warning.
- Three export smoke checks: passed (pages/canonicals, internal assets, discovery files and endpoint inclusion).
- pnpm dependency audit: zero reported vulnerabilities across 55 dependencies at verification time.
- Browser preview: mobile menu and FAQ expansion work; no horizontal overflow at 393 pixels; no browser errors observed.

The build machine uses Node.js 24; CI uses the documented Node.js 22 environment. The upgrade stayed within the same Next.js major release. Audit results depend on the registry's current advisory data and must be rerun over time.

## Production boundary

Namecheap serves static HTML/CSS/JavaScript plus `contact.php`; no Next.js Node server is exposed. The rebuilt static export is the production release artifact. Private enquiry storage and mail configuration are separate from the framework upgrade. Enquiry success confirms private persistence, not notification delivery. Mailbox provisioning was pending at the original handoff.
