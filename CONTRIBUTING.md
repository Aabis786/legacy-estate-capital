# Contributing

Install dependencies with the committed pnpm lockfile. Keep changes focused and describe the user-facing behavior and tradeoffs in the pull request.

Before submitting:

```bash
pnpm build
pnpm test
php -l public/contact.php
```

Verify changed layouts at phone and desktop widths. Do not add production enquiry records, credentials, hosting sessions, or private client documents. Business copy and brand changes need the owner's review. Keep service descriptions within the advertised administrative scope.
